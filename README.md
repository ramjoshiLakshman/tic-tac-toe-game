# Tic Tac Toe Game

A Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

- Two-players game play
- Winner detection
- Draw detection
- Scoreboard tracking
- Turn indicator
- Reset game functionality
- New game option
- Winning combination highlight

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` - Game layout
- `style.css` - Styling and UI
- `app.js` - Game logic

## Future Improvements

- Play against computer
- Difficulty levels
- Sound effects
- Mobile responsiveness
